Claude Code vs Codex vs Gemini CLI

As of 22 October 2026, Claude Code has the deepest agent harness and the most creator workflows built on it, but it starts at $20 a month, while Codex is the only one of the three you can start free and its CLI is open source. Gemini CLI stopped serving free personal Google accounts on 18 June 2026 [26], so it now fits only teams that already pay for Gemini Code Assist or a Gemini API key.

What changed in 2026

  • Gemini CLI's free tier is gone. Google announced on 19 May 2026 that Gemini CLI would stop serving free individual accounts and Google AI Pro and Ultra subscribers on 18 June 2026 [26]. The repo README now says Gemini CLI "was replaced by Antigravity CLI" for those users [27]. The repo's own quota page still lists the old 1,000 requests a day, which is out of date [29].
  • Antigravity CLI is the free Google option now. Its individual plan is $0 with "basic weekly rate limits", and Google does not publish the size of those limits [32].
  • Claude's June 15 billing split was paused. A creator reported that claude -p and Agent SDK usage would move to per-token billing (Claude -p and Agent SDK billing split — what the June 15 change means). Anthropic's support article says the change was paused and that this usage still counts against plan limits [13].
  • Max and Team plans gained monthly API credits on 7 October 2026. Max 5x gets $100 and Max 20x $200, and the credits do not cover interactive Claude Code [14].
  • Codex retired GPT-5.5 for ChatGPT sign-in on 14 October 2026 and now recommends GPT-6.1 Sol [16].

What creators actually use each one for

Claude Code posts are mostly about extending the harness rather than raw coding. Boris Cherny's team tips (Claude Code Team Tips — Boris Cherny's 10 habits for parallel…) and his CLAUDE.md (Boris Cherny's personal CLAUDE.md — plan-first, self-improving rules) set the plan-first pattern, and roundups like 7 must-install Claude Code repos — Obsidian Skills, n8n-MCP… list the skill packs people install. A second cluster is about stretching usage limits: rerouting the harness through OpenRouter (Claude Code on OpenRouter — keep the harness, swap in cheaper models) or letting the top model plan while cheaper subagents execute (Fable orchestrates, Opus executes — cutting frontier-model token spend).

Codex shows up most as a second opinion on Claude's work. Creators run it as an auditor of Claude Code output (Codex + Claude Code — 3 systems to audit CC output with Codex), cross-audit plans between the two models (Claudex skill — Claude and GPT-6 Astra cross-audit plan and build), or call it from inside Claude Code with OpenAI's plugin (Fable 5 plus GPT-5.6 routing — Codex plugin inside Claude Code). Solo builds lean on its scheduled tasks (GPT-6 Astra + Codex one-person company — context files and daily…) and its hands-off asset work, such as a Blender model built and embedded with Three.js (Codex + Blender — agent-built 3D hero asset embedded with Three.js). One tier list ranks Codex and Claude Code level and calls Codex cheaper for comparable output (AI tool tier list May 2026 — Codex and Claude Code top, chatbots C).

Gemini CLI has one strong entry, and it is now historical: a post about the free 1,000-requests-a-day tier (Gemini CLI — free terminal coding agent, 1K req/day, Gemini 2.5 Pro). Creators who wanted a free terminal agent have looked at Kimi Code CLI (Kimi Code CLI — free Claude Code alternative, terminal-first agent), and one agency stack pairs Claude Code with Google Antigravity (AI tools worth paying for — Claude, Gemini, n8n, Neon and Railway…).

Several creators run two of these side by side. One builds a dashboard that drives both Claude Code and Codex subscriptions from one screen (Subscription-powered dashboards — custom UIs that drive Claude Code…), and a trending reverse-engineering repo works with either (Reverse Engineer Anything — trending repo that explains how any app…).

Which one to pick

All three now share the same building blocks: hooks, Agent Skills, plugins or extensions, MCP, subagents and a headless mode. The differences that matter are price of entry, license, and which ecosystem your team already lives in. We did not run our own benchmark, so this page does not rank code quality.

PickIf
Claude CodeYou already pay for Claude Pro or Max, you want the richest set of hooks, skills and plugins (see our best Claude Code skills and plugins), and you want a 1M-token context by default.
CodexYou want to start free on ChatGPT Free or $8 Go, you want an Apache-2.0 CLI you can read and fork, or you want a second model to audit what Claude writes.
Gemini CLIYour company already has a Gemini Code Assist Standard or Enterprise license or Vertex billing. Individuals on a personal Google account are pointed to Antigravity CLI instead.
Two of themYou plan with one model and audit with the other. Claude Code plus Codex is the pairing the corpus shows most, through OpenAI's Codex plugin for Claude Code.

What we could not verify

  • Codex context window size per model: the Codex docs do not state it.
  • Numeric limits of the ChatGPT Free plan for Codex: OpenAI does not publish them.
  • Antigravity CLI's license and the size of its free weekly limits: Google's pages do not state them.
  • The old Gemini CLI figure of 60 requests a minute on Gemini 2.5 Pro: only third-party pages carry it now.
  • Code quality: our corpus records what creators did with each tool, not a controlled same-task test.
