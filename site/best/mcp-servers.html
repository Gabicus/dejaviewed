Best MCP servers, with maintained and archived status

The MCP servers with the best evidence and upkeep as of 22 October 2026 are Playwright for browser control, Context7 for current library docs, n8n-MCP for building n8n workflows, and Figma's official server for design-to-code. Before you install a server from an older list, check it is not one of the reference servers the MCP project archived in May 2025, such as the old Slack, GitHub, Puppeteer or Brave Search servers [3].

An MCP server gives an AI agent a set of tools for one outside system, such as a browser, a design file or an ad account, over the Model Context Protocol [1]. Claude Code adds one with claude mcp add [2]. We took every MCP server named in the 43 saved posts in the DejaViewed corpus that mention MCP (9 S-tier, 19 A-tier, 7 B-tier, 8 C-tier). We checked each server's repo or official docs page and gave it a verdict: 4 keep, 18 try, 3 skip.

Status comes from the GitHub API on 22 October 2026 [5]. Maintained means a commit in the last 90 days, slow updates means 90 to 365 days, and archived means the owner archived the repo. Official, hosted means the vendor of the app runs the server and documents it, with no public repo to check. Install commands are copied from the entry, the README or the vendor's docs.

A server runs with whatever access you give it. Servers that can spend money, such as ad accounts, post publicly, or scrape sites that forbid it carry the most risk, and the reasons below say so where it applies.

Archived reference servers to avoid

In May 2025 the Model Context Protocol project moved most of its original reference servers into an archived repository, and they get no further fixes [3]. That set includes the Slack, GitHub, Puppeteer, Brave Search, Google Drive and Postgres servers that many older lists still recommend. The live reference repo now keeps a small set of maintained examples [4]. Prefer each vendor's own server where one exists.

Where to start

For coding work, add Playwright and Context7 first: one lets the agent see and test what it builds, and the other stops it from guessing at library APIs. Add n8n-MCP if you build n8n workflows, and Figma's server if you turn designs into code. Add account-level servers such as Meta Ads, Gmail or Buffer only for a task that needs them, with the narrowest permissions the vendor offers.

Each server you connect adds its tool descriptions to the agent's context on every turn. Remove the ones you do not use. One S-tier post names idle MCP servers, old skills and a bloated CLAUDE.md as the usual places tokens leak (Claude — Burning tokens for no reason is a skill issue.).

What we could not verify

  • Meta Ads: Meta announced an official MCP server in July 2026, but the entry that covers it does not show which server the creator connected, so it may be a third-party one.
  • JobSpy and Facebook Marketplace: no entry names a repo, so we list the most-starred matching server and say so in its reason.
  • TradingView: several unofficial servers compete and none is named in the entry.
  • REA's GitHub star count looks wrong, so we leave it out.
