Best Claude Code skills and plugins

The Claude Code add-ons with the strongest evidence in our corpus are free patterns, not packages: Boris Cherny's plan-first CLAUDE.md, a primer.md handoff file, and hooks that enforce your rules. Among installs, keep Anthropic's frontend-design and skill-creator, Impeccable for design, Caveman with Codeburn for token cost, and find-skills for discovery. Skip GSD, whose repo is archived and which used about six times the tokens of plain Claude Code in a head-to-head test (Comment “agent” to get my Claude code guides).

We went through the 68 saved posts in the DejaViewed corpus that cover Claude Code skills, plugins, CLAUDE.md files, hooks and memory add-ons (19 S-tier, 25 A-tier, 21 B-tier, 3 C-tier by our ratings). Every item below is something at least one of those posts actually covers. The verdict weighs how strong that evidence is, whether the repo is still maintained, and what it costs you in tokens or setup. The result is 13 keep, 19 try and 3 skip.

Skills are folders with a SKILL.md file that Claude loads when a task matches [1]. Plugins bundle skills, hooks, commands and MCP servers and install from a marketplace with /plugin [2]. Hooks are shell commands that run on events such as before a tool call [3].

Status comes from the GitHub API on 22 October 2026 [4]. Maintained means a commit in the last 90 days, slow updates means 90 to 365 days, stale means older, and archived means the owner archived the repo. Unverified means no repo could be matched to the entry. Install commands are copied from the entry or the repo README, never written by us.

Why try: Single B-tier entry and its prompt is comment-gated, but the idea (over-instruction hurts capable models) is free to apply by hand.

Covered in: Claude setup purge — audit stale CLAUDE.md rules for newer models B

Where to start

Start with the free patterns: a short CLAUDE.md in Boris Cherny's style, a primer.md for session handoff, and one or two hooks for the rules you keep repeating. Then add one design skill (Impeccable or Anthropic's frontend-design, not both plus UI UX Pro Max), and Caveman with Codeburn once token cost matters.

Every skill loads text into context and every plugin can run code on your machine. Read a skill's files before you install it, and remove the ones you stop using. One S-tier post names old skills, idle MCP servers and a bloated CLAUDE.md as the usual places tokens leak (Claude — Burning tokens for no reason is a skill issue.).

What we could not verify

  • Token-saving claims such as claude-mem's "95% fewer tokens" and Graphify's 70x figure are the creators' own numbers. We have not measured them.
  • Claudex and the Scroll World skill are shared only with people who comment on the post, so we could not match them to a repo.
  • Twelve repos were matched by searching GitHub for the tool the entry names, then checking the repo description fits. Entries that name a repo directly are more certain.
