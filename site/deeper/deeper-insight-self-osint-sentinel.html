Dox Yourself First — a scheduled agent that runs the OSINT kit on you

The catalog saved a full attacker toolkit — Sherlock and Alien's Eye for usernames, email-to-account mappers, deleted-Reddit recovery, GeoSpy geolocating photos from plants and shadows — next to the defense: a de-dox checklist written after Meta AI inferred a creator's home from old posts, a data-broker opt-out game, the Flock plate-search transparency site. An agent with a weekly cron can run the offense against you and file the defense automatically. The same tools that took a security team now fit in one scheduled skill.
Alien's Eye · Claude · Claude Code · Flock Safety · GeoSpy · Meta AI · Sherlock · uv

Try It — Action Sketch

Write one skill that runs Sherlock (via uv) and an email-enumeration tool against your own handles and addresses, storing results in a table keyed by date, Add a photo pass: send your last 20 public images to a geolocation model and flag any that resolve within a few km of home, Schedule it weekly, diff against last run, and have the agent draft data-broker opt-out requests from the checklist for each new hit, Falsifier: if three consecutive weekly runs surface nothing new and the opt-outs stick, a quarterly manual checklist is enough and the agent is overhead

Prerequisites: Only run against identities you own, A machine that can run Python CLIs on a schedule, Patience for opt-out forms that need a human signature
