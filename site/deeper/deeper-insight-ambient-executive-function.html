Ambient Executive Function — glanceable hardware for agents and attention

OpenAI built a $230 hardware controller for babysitting coding agents. Someone answered with a MacBook-notch status app, and Bot Crossing turned 80 agents into characters who raise their hands. Separately, NFC stickers make logging a habit a one-tap physical act, and Sharp memory LCDs stay on for days at e-paper power. Combine them into a small always-on desk object that shows what needs you, both agents waiting for approval and your own NOW list, and takes physical taps as input. That turns 'out of sight, out of mind' from a willpower problem into an environment.
Anthropic · Apple Shortcuts · Blender · Blender MCP · Bot Crossing · ChatGPT · Claude · Claude Code · Codex · Codex Micro · GitHub · LingBot-Map · Next.js · Notion · Obsidian · OpenAI · Raspberry Pi · Sharp Memory Display · TouchDesigner · TypeScript

Try It — Action Sketch

Build an ESP32 + 2.7in Sharp memory LCD in a printed stand; it polls a tiny endpoint serving (a) top 3 lines of NOW.md, (b) count of agent sessions awaiting approval via a Claude Code Notification/Stop hook., Stick NFC tags on desk, water bottle and door: tap = 'done/started/leaving', logged by an iOS Shortcut to the same endpoint; the display updates within seconds., Run 14 days logging glance-triggered actions (taps within 2 min of a display change) and agent wait time before/after., Falsifier: if glance-triggered actions fall to near zero by week two (habituation) and agent wait time doesn't drop, ambient display isn't beating a phone notification.

Prerequisites: ESP32 + Sharp memory LCD (~$40), NFC stickers, iOS Shortcuts or Android Tasker, Claude Code hooks
