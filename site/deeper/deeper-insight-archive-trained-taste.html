Escaping the AI House Style — Taste Trained on the Public Domain

Look at the design stacks in this catalog and the same names keep coming back: Impeccable, awesome-design-md, 21st.dev, Emil Kowalski skills. When everyone feeds their agent the same borrowed systems, AI-built work converges on one house style. The way out is the reference corpus — scrape a public-domain archive nobody is mining, like rave zines, arcade flyers, transit posters or historical maps, embed it, find your clusters, and compile them into a DESIGN.md and prompt profile only you hold.
21st.dev · ChatGPT · Claude · Cursor · Figma · Figma MCP · Gemini · Impeccable · Playwright · StopSlop · TensorBoard Projector · Vercel · WebGPU · awesome-design-md · getdesign.md

Try It — Action Sketch

Scrape 2–5K images from one archive (start with rave zines or arcade flyers), embed them with an open CLIP model, and inspect clusters in the TensorBoard projector; tag the 3–5 clusters you actually like, Have Claude write a DESIGN.md per cluster (palette, type, grid, texture, motion rules) plus a JSON image-prompt profile, then build the same landing page three ways: stock Impeccable, cluster A, cluster B, If the clusters hold, train a small image LoRA on the chosen cluster for hero imagery and wrap the whole thing as a Claude skill, Falsifier: if blind raters can't tell the archive-anchored pages from the stock-toolkit page better than chance, the corpus adds nothing the shared stack lacks

Prerequisites: Respect archive licences — public domain or permissive only, GPU or a hosted embedding API, An existing agent design workflow to compare against
