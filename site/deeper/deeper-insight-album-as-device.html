The Album Is a Device Again — Offline Generative Music Objects

Tristan Perich already shipped a symphony as a chip in a CD case. Google's Gemma Translator shows a full speech model stack running offline on a Pi 5 with a printable case and parts list. Local voice cloning fits in 100M parameters, and memory LCDs sip power. Put those together and a song can be a small object that performs a slightly different take every time it plays — the artist's own voice and stems, recombined on device, forever, with no server.
After Effects · Anthropic · Apple Shortcuts · Blender · Claude · FFmpeg · Grok Imagine · Hermes Skills Hub · Khaen · Kimi · Moonshine · Muse Code · Next.js · OpenAI · Pocket TTS · Python · Raspberry Pi · Raspberry Pi 5 · Sharp Memory Display · TypeScript · kimi-k3-in-c

Try It — Action Sketch

Prototype on a Pi Zero 2 or Pi 5: a Python player that recombines 8–12 stems of one song by seeded rules (order, mutes, tempo drift) so no two plays match; no ML yet, Add a local voice layer — Pocket TTS or a small cloned-voice model speaking or singing a variable spoken-word line — plus a memory LCD showing the play number and today's arrangement, Print 10 cases from the Gemma Translator STL as a base, price the run, and pre-sell to existing listeners, Falsifier: if listeners in a blind test prefer the fixed studio take every time, or the BOM forces a price above what 10 fans will pay, the format is a curio

Prerequisites: A song with multitrack stems, Raspberry Pi and basic soldering, 3D printer access
