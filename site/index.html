Install

Clone Gabicus/dejaviewed — adds /dejaviewed to Claude Code. Then hand it your saves and go to bed.

$git clone git@github.com:Gabicus/dejaviewed.git ~/.claude/plugins/dejaviewedPlugin
$git clone git@github.com:Gabicus/dejaviewed.git /tmp/dv && cp -r /tmp/dv/skills/dejaviewed ~/.claude/skills/Skill-only
