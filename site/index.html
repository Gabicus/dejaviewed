⬡ How it’s made

Five passes, one skill

It’s a Claude Code skill. Point it at your saves and it runs the same pipeline that built this site.

01 ──

Pull

Saves come out of Instagram, TikTok, X, Reddit, YouTube, Pinterest and your bookmarks.

◉ 18 collections
02 ──

Transcribe

Reels and videos get run through Whisper, so what was said is searchable too.

◉ 784 transcripts
03 ──

Enrich

Each save gets a real title, a summary, tools, techniques, repos and a tier.

◉ 53 made S-tier
04 ──

Curate

Saves get read side by side; the threads worth pulling become insight dives.

◉ 45 curated dives
05 ──

Publish

Out comes this site — catalog, guides, graphs — plus an agent-readable layer.

◉ 63 guides live

Install

Clone Gabicus/dejaviewed — adds /dejaviewed to Claude Code. Then hand it your saves and go to bed.

$git clone git@github.com:Gabicus/dejaviewed.git ~/.claude/plugins/dejaviewedPlugin
$git clone git@github.com:Gabicus/dejaviewed.git /tmp/dv && cp -r /tmp/dv/skills/dejaviewed ~/.claude/skills/Skill-only
