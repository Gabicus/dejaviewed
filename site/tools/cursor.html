Editor's take

Cursor is thinly covered here: 9 posts carry the tag once three that used the word for the mouse pointer are left out. Where the editor itself appears, it is usually as the place to run another agent. @jens.heitmann recommends it as one of three IDEs to use instead of a bare terminal, describing it as a VS Code fork with AI built in throughout that helps when working with Claude Code (IDE picks). Claude Code co-occurs in 6 of the 9 posts, often named interchangeably as the tool you point at a GitHub repo of shader gradients or liquid-glass effects (design repos). Gemini co-occurs in 4, Veo and Codex in 2 each; one Veo post is a scroll-animation recipe that ends by dropping frames into "your favorite AI coding tool" (scroll effect).

The few evaluative posts are mixed. In a prompt-a-UI challenge, a Cursor attempt got close but v0 did best, and the takeaway is that AI gets you about 80% of a design while hand-tuned CSS finishes it (Build Wars). A launch post framed Gemini CLI's free tier as a threat to paid tools like Cursor (Gemini CLI), and a news clip claims Cursor shipped an agent priced at $200-300 a month with source maps left on, after which the community rewired it to other models (leak claim). That claim is a single, comment-gated report.

For anyone choosing an editor, this archive offers little first-hand Cursor workflow; the Claude mastery guide covers the agent side it is usually paired with.
