Editor's take

Most of these 107 posts treat Claude Code as a harness people customize for whole jobs. Website builds are a common demo: a CLAUDE.md of design rules, the frontend-design skill and a loop where the agent screenshots and critiques its own UI (website recipe), or a DESIGN.md pasted in as a baseline (awesome-design-md). Others launch Meta ads through an Ads MCP (ads pipeline) or turn 36 YouTube videos into a linked wiki (knowledge base).

Repeated habits come largely from Anthropic's Boris Cherny: 3-5 parallel git worktrees, plan mode for complex tasks, and a CLAUDE.md updated after every correction (team tips). A counter-current says less is more: the "simple mode" strips the system prompts and Anthropic found the model slightly smarter without them (simple mode), and one creator urges auditing stale rules written for older models (setup purge). The Claude Code mastery guide collects these patterns.

Cost and limits are the main complaints. Creators reroute the harness to OpenRouter when they hit usage caps, accepting weaker tool use from small free models (OpenRouter swap), and from June 15 `claude -p` and Agent SDK runs were billed per token outside plan limits (billing split). One caption cites an analysis of 6,852 sessions claiming thinking depth fell 67% (session data); it is a single unverified report.

Codex shows up in 9 of these posts, usually as a second model that audits Claude Code's output (Codex audit). Playwright appears in 8, mostly so the agent can check its own render (design stack); Obsidian and ChatGPT each appear in 7, with Obsidian serving as the memory vault (agentic OS). Cursor appears in 6. Many posts are comment-gated teasers with little method shown. The audience is mostly terminal-comfortable builders, though a non-coder uses it to map their own app's bugs (architecture map).
