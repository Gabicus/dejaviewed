Every App Is Headless Now — agents that build their own control surface

Insight class: Arbitrage Opportunity · Difficulty: Hard · Quality: 4/5 Connected entries: 11 · Tools: ARTEMIS, Antigravity, Claude, Claude Code, Codex, DeepWiki, Ghidra, GitDiagram, GitMCP, Gitingest, Google Colab, Grok, OpenViking, Pizza Bot, REA, Reverse Engineer Anything, Salesforce, Ubuntu, Unsloth Studio, VS Code

Thesis

Chamath's claim that software IP stops being a moat once agents call services via MCP assumes the service ships an MCP. The catalog quietly shows you no longer need its permission. 'Build yourself a CLI for this program' covers apps with no API, Reverse Engineer Anything and the Ghidra-backed REA MCP explain closed binaries, and Claude Code already strips a smart TV over WiFi. Put these together and any legacy or closed tool becomes agent-drivable — and Bending Spoons' acquire-and-rebuild playbook shows what that is worth when the software is stagnant.

Why it matters

The long tail of MCP-less software — dental scheduling suites, MLS portals, ancient ERPs — is where small businesses lose hours. Whoever can wrap one in a reliable agent-built CLI sells the finished work rather than the software, which is exactly the AI-native-service model YC is asking for.

Action sketch — how to implement this

Pick one MCP-less desktop tool you or a local business already uses; prompt the agent to 'build yourself a CLI' covering its top 5 actions and log how many need UI automation versus file/DB access

For the stubborn actions, run Reverse Engineer Anything (or REA MCP for native binaries) to find the underlying file formats or local endpoints, and replace UI clicks with direct calls

Wrap the CLI as an MCP server, run a week of real tasks through it, and price the result as a monthly 'we run it for you' service

Falsifier: if the wrapper breaks on more than one vendor update per month, the maintenance cost eats the margin and this is a consulting gig, not an arbitrage

Prerequisites

Comfort with reverse-engineering legality in your jurisdiction

Access to the target software you are licensed to use

An agent with shell and MCP support
