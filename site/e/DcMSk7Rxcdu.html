50k ft — Why care?

Boris Cherny at YC Startup School: Claude Code accepts --system-prompt for a custom system prompt, and an undocumented simple mode (env var CLAUDE_CODE_SIMPLE=1) deletes all system and tool prompts. Anthropic uses it as an ablation and finds the model is slightly more intelligent without them, though product prompts still help it behave as users expect.

10k ft — Key takeaways

• Ablate your own agent prompts to see which instructions actually help. • Over-instruction can cap model capability; keep prompts minimal. • Try simple mode for raw-capability tasks where product guardrails aren't needed.

5k ft — Tools & techniques

1k ft — Deep-dive / try it

Claude Code creator Boris Cherny says the model can actually become slightly more intelligent when its system prompts are removed. Anthropic discovered this through ablation testing, where the team strips away instructions and tool prompts to measure what is genuinely improving the model. The surprising result was that more prompting didn’t always produce more intelligence. In some cases, the additional instructions were constraining what the model could do. For founders and developers building with AI, this is a useful reminder that prompting is part of the product architecture. Every instruction added to an agent can shape its behavior, narrow its decision-making, and influence how well it handles problems outside the exact workflow you designed.
