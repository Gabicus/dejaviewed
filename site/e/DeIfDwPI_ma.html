50k ft — Why care?

An open-source Minecraft mod built on Claude's agent system: a Foreman tracks tasks, ordering, decisions and inter-agent messages, workers each get an isolated copy of the code, and nothing merges until approved. Agents commit under their own names and can be messaged mid-task, and they walk over to find you when they need input.
agentsopen sourcesoftware development

10k ft — Key takeaways

• A coordinator that logs decisions prevents agents re-litigating work • Give each worker agent an isolated code copy and gate merges on approval • Per-agent commit identities make blame and review easy • Spatial UIs can make agent activity legible

5k ft — Tools & techniques

AgentCraft, Claude, Minecraft AI agents, agent attribution, isolated worktrees, multi-agent orchestration

Someone turned Minecraft into a workplace where AI agents write real code while you walk around and watch. Meet Agent Craft, built by an engineer called Blendy and released as open source software. It's a Minecraft mod running on Claude's agent system and the code it writes goes into your actual projects and every agent works in its own space. There's a lead agent and a team of workers all managed by something called the foreman. It keeps track of every task, the order they run in, what the agents have said to each other, and what's already been decided. When an agent takes a job, it gets its own isolated copy of the code to work in. Nothing touches your main project until the work is approved. Here's where it gets insane. Every agent commits its work under its own name so you can see exactly which one wrote which line. They also message each other while they work and a message sent to a busy agent reaches it in the middle of a task. But the craziest part? Watching AI write code has always meant staring at text in a terminal. Agent Craft turns it into a building you can walk through, where the agent comes and finds you when it needs something.
