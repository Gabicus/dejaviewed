50k ft — Why care?

Early demo of an XR infinite canvas on Meta Quest 3 synced with a desktop canvas: drop reference images into a sphere, put your hand in it and speak a request (e.g. components visualizing multi-agent progress), make a fist to send it to Claude Code agents under custom orchestration, and watch results build up in place.

10k ft — Key takeaways

• Gesture-to-send keeps hands-free XR workflows fluid. • Next frontier: point at objects and describe changes in place. • Spatial containers are a neat metaphor for scoping agent context.

5k ft — Tools & techniques

Claude, Claude Code, Meta Quest 3 AI agents, agent orchestration, spatial prompting, workflow automation
