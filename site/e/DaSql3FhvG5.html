Transcript excerpt
Shell Sort is an optimized version of Insertion Sort, and what makes it faster is a pretty clever change. Insertion Sort works by scanning the list, comparing each number to the one before it. If it's smaller, it slides backwards until it hits a number smaller than itself. But when a small number starts near the end of the list, it can only move back one step at a time, which makes Insertion Sort slow on large unsorted arrays. Shell Sort fixes this by comparing numbers that are separated by a gap. It runs Insertion Sort on these spaced-out subsequences, allowing small numbers to move large distances across the list much earlier. The gap is reduced with each pass until it reaches one.
