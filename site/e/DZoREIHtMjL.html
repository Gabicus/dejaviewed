50k ft — Why care?

Programmable NFC stickers on a water bottle trigger an Apple Shortcut that logs each finished bottle to a tiny Next.js/TypeScript web app, surfaced as a home-screen widget. Part two of an IRL vibe-coding series; next step is a Raspberry Pi force sensor to log automatically.
creative codinghardwaresoftware developmentvideo production

10k ft — Key takeaways

• NFC sticker + Shortcuts + a simple web endpoint = one-tap physical logging. • Physical triggers make boring tracking effortless. • Upgrade path: sensors (force/weight) on a Raspberry Pi for passive capture.

5k ft — Tools & techniques

Apple Shortcuts, Next.js, Raspberry Pi, TypeScript NFC automation, code generation, vibe coding
