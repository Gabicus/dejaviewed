Gemma Translator — offline speech translation on a Raspberry Pi 5
repoS-tier

50k ft — Why care?

Google open-sourced Gemma Translator: Moonshine for speech recognition, Gemma for translation and a TTS model for voice, all on a Raspberry Pi 5 with no network at ~7 tokens/sec, enough for live Spanish–Mandarin conversation. Repo includes code, parts list (battery, touchscreen, speaker, micro keyboard with language knob), deployment script and printable STL case.
LLMhardwareopen source

10k ft — Key takeaways

• Complete BOM and STL files make it a weekend build. • Full speech-to-speech translation fits on a Pi with no cloud. • ~7 tok/s is enough for conversational latency.

5k ft — Tools & techniques

Moonshine, Raspberry Pi 5 API integration, on-device inference, speech-to-speech translation

Transcript excerpt
Google ran a live Spanish to Mandarin conversation on a Raspberry Pi with no internet access. Meet Gemma Translator, which handles the translation on the board itself. Moonshine does the speech recognition, and a third model generates the voice reading it back. All three run on the Pi, no API calls, no server, no network. It pushes about seven tokens a second, which is slow for a language model and fast enough to hold a conversation. And that's where the hardware stops being the limit. A Raspberry Pi 5 costs less than a pair of headphones. Add a battery pack, touch screen, a speaker, and a micro keyboard with a knob for switching languages. Two modes let one person drive both sides or two people run their own mics. Print the case yourself. The STL files are included. Here's where it gets insane. Google published all of it. The code, the parts list, the deployment script, the enclosure files. You can clone the repo and build one. But the craziest part? Running a model like this used to mean a server rack and a connection to it. This one fits in your hand. If you want to stay updated with the latest tech news, follow for more.
