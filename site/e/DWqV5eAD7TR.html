How we reduced token waste (caused by pure laziness) How many of you do this? 👇 Typing commands into AI like: npm run deploy npm run build npm test …when you could run them in 2 seconds from the terminal. We realized we were doing it too. Simple commands, already defined in project config files, automation scripts, and build systems… yet we were still sending them through AI → wasting tokens. So in PromptOps we introduced a Smart Action Detector.
