50k ft — Why care?

Karpathy's autoresearch runs continuous keep-or-revert experiments against a measurable target (83 runs, 15 kept); OpenSpace auto-fixes, improves and learns skills from real usage; CLI-Anything wraps apps like GIMP, Blender and Inkscape as CLIs; claude-peers lets separate Claude Code sessions talk; gws is a Google Workspace CLI.

10k ft — Key takeaways

• Use claude-peers for generator + evaluator sessions with instant feedback • autoresearch only works on targets with a binary improved/not-improved metric (e.g. speed) • gws gives Claude Code full Google Workspace access from the terminal

If you use Claude code then here are five open source projects that just came out this month that you got to check out. Now you've probably heard of this first one unless you are living under a rock and that is auto research by Carpathi. This basically brings in machine learning type experiments into Claude code. We just point Claude code at something we want to improve. Imagine you created some sort of Python app and you want it to run faster and then auto research will run a bunch of experiments continuously to try to improve that product. The example given here had 83 experiments run in succession and it kept 15 of the improvements. Now you need to make sure you're testing something that sort of has a binary yes that improved no it didn't like the speed of something but if you do that this is super useful. Number two on the list is open space and this is all about self-improving skills. You point this project at some sort of a task and then it evaluates your skill usage and put some into three buckets auto fix if the skill breaks auto improve if the skill is actually working but the patterns can be better and then auto learn. So essentially this captures winning workflows from actual usage from their tests on real world use cases. They're saying it improves token consumption by 45 percent and that it increased the income generated using the GDP Val economic benchmark by 4.2 times.
