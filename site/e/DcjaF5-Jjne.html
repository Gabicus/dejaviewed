50k ft — Why care?

A team built an MCP server for their context-sharing platform so any AI can list and read shared ICM templates (folder-based LLM wikis with instructions and scripts) without logging in or syncing via GitHub, SharePoint or zip files. New uploads from teammates show up immediately.

Transcript excerpt
Look at this, we have our own MCP now. Now I can access hundreds of second brains with the click of a button. Think about it, right now a lot of people are building these second brains or these folder structures, LLM wikis. Basically a folder with instructions and scripts and things like that that makes an AI way less stupid. Right now, if you want to work on it with other people, especially if it's more than a hundred, you're having to push it on GitHub or SharePoint or just email a zip file to someone else. Sometimes those can work great, as long as you're all using the exact same AI and the exact same method for downloading it constantly. That removes the speed, you want people to be able to work and edit and move with them while simultaneously sharing that context across all these different AI that people have in different companies or places. Maybe you're trying to share it with a company and they don't have an AI at all. Well, if you've seen videos about our software, it solves most of those problems, but one thing was really annoying that people were asking about. I want to be able to push updates and change it like a proper developer or builder would. We created an MCP server.
