50k ft — Why care?

2D animated skit where a user exploits a genie's 2-bit wish counter: wishing for negative wishes should underflow to the maximum value, so he first upgrades the data type to 64 bits and ends with ~18 quintillion wishes. A fun explainer of integer overflow.

10k ft — Key takeaways

• An unsigned 64-bit max is about 1.8×10^19 • Underflow wraps to the type's maximum value
