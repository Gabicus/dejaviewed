1k ft — Deep-dive / try it

Chamath said it on All-In this week, reacting to a launch two days earlier: the value of IP in software doesn’t exist. Not shrinking. Doesn’t exist. The context is headless software — software with no interface. No buttons, no dashboard, just the engine exposed so something else can drive it. MCP is the standard that lets an agent talk to it. So you stop touching software. You tell an agent what you want, and it picks which tool does the job, optimizing for speed or cost or accuracy. If anyone can ship software and agents decide which one runs, the interface was never the moat. Build for the agent.
