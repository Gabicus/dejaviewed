Transcript excerpt
If you're not leveraging hooks in Claude code, you are making your experience far harder than it has to be. Hooks are essentially triggers that you put in your Claude code that will perform an action whenever they get flagged. Here are three hooks that benefit me daily in my Claude code work. My first hook is actually one that I built myself, which is my anti-deletion hook. And what it does is in yellow mode, it prevents Claude code from deleting any files and instead moves it to a staging folder for me to review and delete later if I choose to do so. Second is my notification hook, which basically whenever I start a Claude code session and alt tab in between and I'm not using yellow mode is that this will chime to get my attention to get back into Claude. Lastly, this is one of my newer ones, but I've turned this auto research skill into a hook for whenever I work with anything in marketing that requires copy or visual designs, I have it auto research AB testing for refinement. Now you should make hooks that are specific to you as these are very powerful personal systems, but if you wanna get started with my hooks that I have made, just comment hook and I'll DM you mine directly.
