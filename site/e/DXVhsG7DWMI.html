LingBot-Map — Autoregressive 3D world understanding in real time Open-source GitHub project by Ant Group’s Robbyant team. A feed-forward 3D foundation model designed for streaming reconstruction from video. What makes it different: • Processes scenes sequentially (no full video required upfront) • Reconstructs camera pose and dense 3D geometry in real time from a single RGB stream • Uses a Geometric Context Transformer combining spatial grounding, geometry understanding, and temporal memory Core capabilities: • Real-time streaming inference (~20 FPS) across long sequences • Continuous mapping and localization (SLAM-like behavior) • Works directly from live video or image streams • Handles long-range consistency and drift correction • Efficient transformer architecture with KV-cache for …
