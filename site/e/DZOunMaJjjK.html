50k ft — Why care?

Graphify is a free open-source tool that converts a repository, or a folder of markdown and unstructured notes, into a knowledge graph that Claude Code or other coding agents query as a map. Answers come from the graph instead of re-reading files, so codebase questions use far fewer tokens: a kind of lightweight RAG.
agentsopen sourcesoftware development

10k ft — Key takeaways

• Build the graph once per repo and have the agent query it before opening raw files. • It also works on markdown-only repos as a lightweight retrieval layer. • No content to act on.
