100k ft — What is this?

50k ft — Why care?

Graphify is a free open-source tool that converts a repository, or a folder of markdown and unstructured notes, into a knowledge graph that Claude Code or other coding agents query as a map. Answers come from the graph instead of re-reading files, so codebase questions use far fewer tokens: a kind of lightweight RAG.
agentsopen sourcesoftware development

10k ft — Key takeaways

• Build the graph once per repo and have the agent query it before opening raw files. • It also works on markdown-only repos as a lightweight retrieval layer. • No content to act on.

Transcript excerpt
Graphify just solved Claude Code's memory problem. Graphify is a free open source tool that allows Claude Code, or any AI coding agent for that matter, to take a look at a repository and turn it into a knowledge graph. That knowledge graph, like you see here, acts as a map for Claude Code so that it can more effectively answer questions about a repo, and by more effectively, I mean using way less tokens than it otherwise would. And while it's truly meant for code bases, you can also point it at repos that have more unstructured data or just mark down files as well. So it almost acts as like a rag light system. So very flexible, and you should definitely check it out.
