50k ft — Why care?

Microsoft open-sourced SkillOpt: a base model runs a task, an optimizer rewrites the skill instructions from results, successful paths are separated from failures, and edits that don't beat the benchmark are auto-rejected. Claimed to beat hand-written prompts and TextGrad and to transfer across models.

• Gate every rewrite on beating the benchmark. • Model-agnostic, so optimized skills port across providers. • Treat skill instructions like trainable parameters with an eval set. • link: https://github.com/microsoft/SkillOpt

🚨 MICROSOFT OPEN-SOURCED SELF-EVOLVING AGENT SKILLS SkillOpt lets skills improve themselves. A base model runs the task, an optimizer rewrites the instructions based on results.
