Transcript excerpt
You need your own cloud code powered agentic OS. And by that, I mean a system where we have cloud code is our engine. And it's able to do essentially every single business task for us. It has a memory system with obsidian. It's connected to our entire Google suite. And we have a set of skill packs for research, content, and the ability to add any set of custom skills and automations that we want. On top of that, we need to be able to bundle that entire functionality into a dashboard slash command center that is great for us, but also something that we can package and sell to clients. Or just give it to members of our team and have them use it that way. There is a ton of value in these agentic OS setups. And this is where the space is headed, especially if you're someone who's running your own AI agency.
