1k ft — Deep-dive / try it

Built a sort of “EMP grenade” using an ESP32, an nRF24 module, a battery board, and a simple web interface. The device creates heavy interference on the 2.4 GHz spectrum, which is the same band used by WiFi, Bluetooth, wireless speakers, headphones, smart devices, and a lot more. For this build I programmed the ESP32 to host its own WiFi control panel where you can arm the device and trigger a countdown timer before activation. After that, the RF module starts transmitting noise across multiple channels simultaneously. Everything fits into a tiny portable enclosure powered by a rechargeable battery. Transcript excerpt
Day 29 of pointless gadgets. My neighbor has been blasting reggiton every single day non-stop. So I built an EMP grenade to shut down all Bluetooth connections in range. It uses an ESP32, a battery module, an RF module, and some wiring. Once the code was ready, I uploaded it, connected everything and dropped it into a small box. There we go. Portable RF killer. It works by flooding the 2.4 GHz band with noise until nothing can communicate. It works with a Wi-Fi portal to arm it remotely and set a timer for deployment. Once it is armed, the portal shuts down and there is no way to stop it. Perfect to hide under a table for a surprise activation or just place it in plain sight next to your target. Let it count down and watch every nearby connection disappear.
