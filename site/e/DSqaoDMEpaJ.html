50k ft — Why care?

Because color is a vector, an image can encode an equation, so y=x² becomes a black-to-yellow gradient. Rows or columns of an image can hold whole sets of parametric equations. The artist uses textures as equation stores in TouchDesigner to build forms like jellyfish, and explains it in a DATLAB NYC talk.
artcreative coding

10k ft — Key takeaways

• Each row or column of an image can be its own equation, so one texture holds many. • Store equations or parameter sets in image pixels and treat textures as data. • This is a practical GPU-friendly pattern for TouchDesigner and shaders.

One of my favorite facts about mathematics is that color is technically a vector and what that means is that you can actually store equations as images. For example, the equation y equals x squared is just a gradient starting from black all the way to yellow and the in-between color is like kind of orangeish and something else that's really interesting is that because images are in two dimensions you can store like entire sets of equations either through using the rows or the columns of an image. And this is basically how I make a lot of my art. I treat images as a method of storing parametric equations and with those parametric equations they build really cool things like jellyfish.
