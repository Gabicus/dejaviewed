50k ft — Why care?

Walkthrough of running an abliterated Qwen 3.5 9B GGUF (the base of PewDiePie's Ajax model) locally: download from Hugging Face, install llama.cpp via Homebrew, start llama-server with context size and port, then point the DeepSeek harness at the custom endpoint. Also mentions PewDiePie's Odysseus agent harness.

10k ft — Key takeaways

• A 16-bit 9B model (~17 GB) runs on a 32 GB MacBook Pro • Abliterated models remove refusals more thoroughly than plain uncensored fine-tunes • Any agent harness with a custom OpenAI-compatible endpoint can drive it • brew install llama.cpp then llama-server -m <model> --ctx-size --port 8080 • link: https://brew.sh
