50k ft — Why care?

From June 15, programmatic Claude usage through `claude -p` and the Agent SDK no longer counts against Pro/Max plan limits and is billed per token instead. That hits third-party harnesses like OpenClaw and OpenCode that ran on subscription quota. The creator argues good context and folder structure lets one interactive agent do the same work.
