50k ft — Why care?

Transcript excerpt
One of the biggest problems plaguing most RAG systems is that you can't ingest documents that aren't text. And while a light RAG is awesome, it's one of those RAG systems that has this issue. However, if we combine that with RAG anything, we can solve that problem and create a RAG system, a graph RAG system that can handle both text and any other sort of document, whether that's image, charts, graphs, you name it. So if you're looking for a RAG system that you can either run completely locally or vary inexpensively, the RAG anything plus light RAG combo can't be beat. And you can combine it with clock code.
