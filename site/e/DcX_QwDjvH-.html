50k ft — Why care?

Open-source tool that fetches a page and returns a tidy numbered text view so agents can read, follow links and search for hundreds of tokens instead of tens of thousands of raw HTML; mimics a real browser to slip basic blocks. Spotted on Hacker News.

10k ft — Key takeaways

oc AI agents, token-efficient browsing

1k ft — Deep-dive / try it

Your AI agent does not need 10,000 tokens just to read a webpage. Turn any website into a compact command line interface for AI agents, cutting browsing costs from tens of thousands of tokens to just hundreds. This tool fetches a page and returns a tidy, numbered view, allowing agents to read, follow links, and search without the massive overhead of raw HTML. It even slips past basic blocks by mimicking a real browser. The single most impressive thing is that it lets an agent browse a live site using less data than a single tweet, making complex web navigation incredibly cheap. If you are building AI tools, this is the fix for your token bill. Check it out. Open source: only-cli/oc Spotted on Hacker News.
