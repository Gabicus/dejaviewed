If you use Claude Code, then here are three GitHub repos that just came out in the last week that you need to check out. Number one is CLI Anything. This is from the makers of Lightrag, and this allows you to point the CLI Anything tool at any open source software and have Claude Code create a CLI tool for that software. If you've been paying attention, you've noticed the shift to CLI tools from MCPs, so this is huge. And the second one is GSD too. We've gotten an update to the Get Shit Done framework. While that used to be almost exclusively for Claude Code, now it's been turned essentially into its own standalone CLI using the Pi SDK. So this allows you to do a lot more if you're outside of the Claude Code framework. However, you won't be able to use your Claude Max plan. I mean, you can try, but you might get banned. And lastly, we have GSTAC, which is from Gary Tan, the CEO of Y Combinator. This is essentially how he sets up his Claude Code. So if you want some insight into how other people are solving some problems with this tool, definitely take a look.
