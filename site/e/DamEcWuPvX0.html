Most people don't realize that Cloud Fable 5 can run for hours unintended, dispatch its own subagents, and do a whole week of work in a single night. Here's how to build an actual agentic OS using Fable 5. Start by configuring the agentic OS engine. The model string should be set to Fable 5, and make sure to set max tokens to 64k, so it caps the thinking plus the responses. Effort is always set to low to max, but never extra high unless you're working with an agentic loop. And here's the part most people miss. Refusals need to come back as HTTP 200. In this way, your scripts have to check for stop, reason, refusal, and not just exit code. Create a batch script called loop.sh and it runs on a cron drive every morning and runs your entire system. First, use a cheap AI model like Gwent to look at your project. And ask if anything changed or needs attention. If yes, Fable steps up as the manager. It does not do the actual work, but writes down exactly what needs to be changed. Then use Sonnet to do the actual work, and a fresh copy of Fable that checks it like an inspector. Next, build up the report card. Every task the system finishes gets logged as a pass or fail, and each type of task will earn its own grade over time. Once something passes 20 times with a 95% success rate, the system is then allowed to do it completely on its own.
