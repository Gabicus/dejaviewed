Breaking: Opus 4.7 has just been released. Anthropic has shipped more updates than leaks this past week. Here are the 3 most important ones you need to know going into this week. /routines Desktop app redesign Managed agents + agent teams #claudecode #claude #aitools #vibecoding
Transcript excerpt
Anthropic has seemingly fixed all the leaks in their ship because there has been more updates than leaks in the past few days. Also, this video is being interrupted by the fact that Opus 4.7 just came out. Now back to your regular scheduled program. Here are the three updates you should know going into this week. The first and actually one of the most useful updates is Slash Routines. This was formerly known as Schedule when it was local only, but Anthropic has released a way for you to set up automations, tasks, on a schedule, and then have it set up in their cloud using this Routines feature. Next news thing you should know is the upgrade to the desktop app. Anthropic has been paying attention to a lot of our sessions and are realizing that many of us are using 4 plus sessions of cloud code in parallel, so they upgraded their app to make running parallel agents more convenient. Last is the new managed agent and agent team harness update. Anthropic has been really diving into the capabilities and coordination of agent teams and has made it a lot easier to spin up a team for a project and let them run on their own for a longer period of time. If you run agents, you should check out this update. I actually think we're going to be seeing a lot more updates from the big three over the next month, so keep your eyes and ears open.
