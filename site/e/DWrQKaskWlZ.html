Just by coming to this URL here, you can get free API access to NASA's Earth Observatory Natural Event Tracker. And this API allows you to get real-time information on all kinds of weather events from around the world. So you can find data on earthquake events, floods, landslides, severe storms, and even wildfires. And a bunch of other stuff, too. The documentation comes along with a lot of examples on how you can get certain data that you're interested in. And there is no API key required.
