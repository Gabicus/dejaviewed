1k ft — Deep-dive / try it

This is how AI actually learns. 🧠📉 Backpropagation can be understood by imagining a neural network’s total error as a point on a huge, high-dimensional loss surface, where every direction represents a different model parameter. Each parameter influences the model’s overall loss, and the gradient combines all of those partial derivatives to show how the loss changes with respect to every parameter. Using the chain rule, backpropagation efficiently calculates this gradient across the entire network. The negative gradient points in the direction of steepest descent. You can think of it like rolling a ball downhill, where each step moves the model toward a region with lower loss. The network repeats this process over and over, adjusting its parameters to gradually reduce error and improve…
Transcript excerpt
We can do this efficiently by computing the slope of each of our parameters with respect to our loss, combining these slopes into a vector called the gradient, and using the gradient to make iterative updates to our weights. Let's explore, as we did last time, how our loss varies with a single model parameter by plotting our loss as a function of m2. Our m2 parameter in our Paris neuron currently has a value of 0, resulting in a loss of 2.45. If we increase the parameter's value to 0.1, we can recompute our outputs, and see that this increases our probability of being in Paris, according to the model, to 0.107, reducing our loss to 2.24. Now, with these two computations of our loss for different values of m2, we've effectively estimated the value of our slope, delta L over delta m2. This tells us that if we increase m2, our loss will go down, increasing model performance. We could theoretically do this for all six parameters in our model, and use these estimated slopes to guide the gradient descent learning process.
