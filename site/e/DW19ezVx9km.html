Transcript excerpt
Telling Cloud Code to talk like a caveman might actually make it smarter as well as save tokens. So this is the caveman repo and what might have started as a meme on Reddit might have some actual legs. You can see here that by having Cloud Code use this repo which strips out all the filler words when it gives you responses, you're able to save 60, 70, 80% of your output tokens on the text prompt itself, not total token usage, but the actual prompt that gives you. But even more importantly, this idea of making your large language model concise might be linked to better outputs. This study that came out last month pretty much said that. It showed that when we had larger large language models think open weight models of 400 billion plus parameters, when we told them to be more concise, they actually gave better outputs significantly so. Now the study is linked in this caveman repo if you want to take a look at it, but the caveman repo itself is very very simple. It's simply a set of skills telling Cloud Code to cut all the filler and it has different levels. So you can be an ultra caveman, a full caveman or a light caveman and it's also important to note that this doesn't change how Cloud Code works under the hood. All the code is the same, all the thinking is the same, it's just the actual text outputs. So as the great American philosopher Kevin Malone once said, why use many word when few do trick?
