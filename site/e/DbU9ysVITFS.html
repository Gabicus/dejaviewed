Transcript excerpt
LiDAR scanners are amazing, but they are also incredibly expensive. I really wanted one, so I started building one myself, with a Raspberry Pi and a LiDAR sensor and a 3D printed housing. It might not be as high quality as a Leica handheld scanner, but for most scanning jobs, it's perfect. Without any expensive proprietary software and strange file formats, you can use it to create 3D maps of buildings, archaeology sites, caves, or parks and gardens. I got a 3D of a tree. I got a lot of supportive messages and questions on where to find the build plan for this device, so the maker community can build it as well. Here it is, lots of words, the wiring plan, the code, and the complete CAD and printing file to build a Peppa Cam yourself. I've got plenty more ideas for new projects, and I wouldn't call the components for these instruments cheap, so it would be brilliant if I could get your support so I can make more projects like this and show you how I build them. Comment build plan and I'll send you the details.
