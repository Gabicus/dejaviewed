DATA CONTROL This project is built around a system designed to visualize scientific datasets such as those from NASA, CERN, and other open research sources in real time. The system allows different types of scientific data to be imported and translated into data-driven particle structures and visual environments. The project was developed using a pipeline based on Kinect, TouchDesigner, and Unreal Engine, enabling human motion to directly interact with and control the data-driven particle systems in real time. The work is based on data visualization techniques. Translating complex datasets into visual structures has been a scientific and artistic practice for centuries, and this project continues that tradition through contemporary generative systems.
