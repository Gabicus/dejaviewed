50k ft — Why care?

Following Andrej Karpathy's viral post on LLM-maintained knowledge bases, Claude Code ingested 36 YouTube videos, extracted tools, techniques and skills, and built an interlinked graph of documents (hubs like 'Claude Code' linking to Playwright, browser automation, ClickUp) with summaries and source links.

10k ft — Key takeaways

• Have the agent extract tools/techniques per source so hubs emerge naturally • Keep source links in each node so the wiki stays verifiable • Paste Karpathy's post into Claude Code and ask it to replicate the system on your own corpus

5k ft — Tools & techniques
