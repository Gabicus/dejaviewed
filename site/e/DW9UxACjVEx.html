SpyDance just released, for free, code that does what companies are trying to charge a premium for. Putting pressure on anyone without any real differentiation, they built a complete agent automation system and open-source it. It does research, writes code, builds websites, creates decks, even generates videos, all by itself, and it runs on its own machine. 100% open-source. Agent orchestration is not new. It already existed with auto-gen, land graph, and open-clore. But the problem has always been execution. In practice, most of the systems still behave like pipelines. Predefined steps, fixed order, and limited adaptation during runtime. Even with multiple agents, there is strong sequential dependency, and message passing overhead that creates bottlenecks. Dear Flow 2.0, by SpyDance, changes how execution is handled. Given an objective, the system builds hierarchical task structure. This is not a fixed list. It can expand or reorganize during execution, based on intermediate results. Each part of this structure is assigned to different agents. These agents run in parallel with local context, but share a global state that is continuously updated. Commodination happens through this shared state, not direct message passing. This reduces reordering constraints, and allows independent progress across different parts of the system. There's also an internal validation loop. Outputs are not treated as final. They are evaluated, and if necessary, reprocessed or re-assigned.…
