50k ft — Why care?

Carbonyl (github.com/fathyb/carbonyl) is an MIT-licensed Chromium build that renders real web pages directly in a terminal, idling at 0% CPU. Useful for browsing over SSH, headless boxes, or giving terminal-bound agents a real browser.
open sourcesoftware development

10k ft — Key takeaways

• MIT-licensed, so you can embed or fork it • Run a real browser over SSH or on a headless server • Zero idle CPU makes it cheap to leave open in a tmux pane • link: https://github.com/fathyb/carbonyl
