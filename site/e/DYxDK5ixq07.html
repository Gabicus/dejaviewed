50k ft — Why care?

A recipe for automating a repetitive business. First run each process by hand and record it on Loom. Then feed each transcript to Claude to write a skill, run the skills manually and patch them when they fail, and finally put each skill on a scheduled task. As an advanced step, skills log their own failures and a meta-skill fixes the others, in the spirit of YC's 'self-improving startup' and Hermes Agent.
agentsproductivityprompt engineeringvideo production

10k ft — Key takeaways

• Do the process by hand first, then record it, because the transcript becomes the skill spec. • Have skills log their issues and add a fixer skill that improves the others. • Run new skills under supervision until they stop failing, then schedule them.

5k ft — Tools & techniques

Claude, Hermes Agent, Loom, Obsidian scheduled agents, self-healing skills, skill authoring from transcripts
