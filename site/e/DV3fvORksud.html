If you're all like me and feel very overwhelmed by all the different MCP servers and plugins and skills and agents and MD files that you can hook up and augment your Claude code with, I made something that might help with that. This is my Claude command center. It basically just checks to see like what model are you running, what MCP servers are you rocking with, what your plugins, what are your skills, what are your agents. It also just shows me what projects I'm working on and their status, right? Pretty cool. It's got a graph mode. So you can see all the plugins and the agents connected to your Claude and then which MCPs live inside which project. You can also search for different MCPs or plugins or skills. It searches GitHub repos and then you can install them into a specific project. Lastly, it's got this section here, which just displays all your .md files. So I've got a Claude.md and I can see that and edit it here. But it's just handy to see where it lives in all my different projects. And then I've got a primer one as well, which just helps for memory. But I just felt a little bit overwhelmed with trying to manage all these different .md files across different projects. I can even add new ones if I want to. So pretty cool.
