Skills That Earn Their Lines — benchmark-gated self-editing plus subtraction

Successor to the harness and second-brain dives. Those stop at 'append a lesson after every mistake'.
What a pro adds: Following Microsoft SkillOpt (marc.kaz), they treat skill instructions as trainable parameters with an eval set and gate every rewrite on beating the benchmark, auto-rejecting edits that do not.
Proof it worked: On the held-out eval, the ratcheted rule set beats the starting set by more than the measured run-to-run variance…
Biggest trap: Monotonic ratchet: only adds, never deletes. Fix: run the ablation sweep and delete what removal does not hurt.
