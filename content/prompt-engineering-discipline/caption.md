Prompt Engineering Isn't Dead — It Just Grew Up

Prompt engineering evolved from 'add please' to a real discipline: structured frameworks, adversarial testing, llms.txt standards, and system-level prompt architecture that shapes model behavior at scale.
What a pro adds: A prompt engineer at a lab would treat prompts like code: versioned, reviewed, and gated by eval sets with expected outputs and graders, so changes are measured instead of argued.
Proof it worked: promptfoo eval results in CI: pass rates per prompt version on held-out cases, and a deliberately bad edit that CI rejects.
Biggest trap: Teaching to the test. Fix: write held-out cases first, rotate cases, add rubric graders.
